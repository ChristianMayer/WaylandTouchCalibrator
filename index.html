What is the "Normalized Matrix" vs "Pixel Space Matrix"?

Normalized Matrix: Wayland compositors (like Sway, Weston) and libinput use this matrix to apply touch calibration independently of the actual screen resolution. It operates on normalized coordinates ranging from 0.0 to 1.0 (e.g. [0..1] x [0..1] mapping to [0..1] x [0..1]). The format is c0 c1 c2 c3 c4 c5.

Pixel Space Matrix: This matrix maps input coordinates in absolute pixels directly to output coordinates in pixels. It's used mostly for legacy X11 setups (like using xinput set-prop) or custom applications that work directly with absolute pixel values rather than normalized ratios.
